# CTO Dinner — Task List

High-level action items for the dinner funnel. Each line is a whole category, not a tactical step.

Live funnel: https://ziad-from-sawa.github.io/cto-dinner-funnel/

## Set up
- [ ] **Lock the basics** — date, number of seats, budget, format.
- [ ] **Secure the anchor guests** — the names everyone else gets sold on. Highest-leverage item; everything else leans on it.
- [ ] **Book the venue.**
- [ ] **Build the target list** — the right ~219 contacts, tiered, with LinkedIn + work emails.
- [ ] **Set up the system** — LinkedIn automation, email sending, Calendly, the sign-up page, and a simple tracker.

## Write the copy
- [ ] **LinkedIn outreach sequence** — connection request + the 3 messages.
- [ ] **Backup email sequence** — the email version for people LinkedIn didn't reach.
- [ ] **Content posts** — the full run of posts that drive the inbound sign-ups.
- [ ] **Post-call email sequence** — everything from "thanks for the call" through "see you tomorrow."

## Launch & run
- [ ] **Test and launch** — start with Tier A, watch the early numbers, then scale.
- [ ] **Run outreach and take the calls.**
- [ ] **Manage confirmations and the waitlist** as seats fill.

## The dinner
- [ ] **Run the pre-dinner emails and lock the final headcount.**
- [ ] **Host the dinner.**
