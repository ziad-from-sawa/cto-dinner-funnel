# CTO Dinner — Task List

High-level action items for the dinner funnel. Each line is a whole category, not a tactical step.
Adam carries 5 of these himself (anchors, the four copy sets, and the calls); the rest is system and ops.

Live funnel: https://ziad-from-sawa.github.io/cto-dinner-funnel/

## Set up
- [ ] **Lock the basics** — date, number of seats, budget, format. *(Adam + Ziad)*
- [ ] **Secure the anchor guests** — the names everyone else gets sold on. Highest-leverage item; everything else leans on it. *(Adam)*
- [ ] **Book the venue.** *(Ziad)*
- [ ] **Build the target list** — the right ~219 contacts, tiered, with LinkedIn + work emails. *(Ziad)*
- [ ] **Set up the system** — LinkedIn automation, email sending, Calendly, the sign-up page, and a simple tracker. *(Ziad)*

## Write the copy
- [ ] **LinkedIn outreach sequence** — connection request + the 3 messages. *(Adam)*
- [ ] **Backup email sequence** — the email version for people LinkedIn didn't reach. *(Adam)*
- [ ] **Content posts** — the full run of posts that drive the inbound sign-ups. *(Adam)*
- [ ] **Post-call email sequence** — everything from "thanks for the call" through "see you tomorrow." *(Adam)*

## Launch & run
- [ ] **Test and launch** — start with Tier A, watch the early numbers, then scale. *(Ziad)*
- [ ] **Run outreach and take the calls.** *(Adam runs the calls)*
- [ ] **Manage confirmations and the waitlist** as seats fill. *(Ziad + Adam)*

## The dinner
- [ ] **Run the pre-dinner emails and lock the final headcount.** *(Ziad)*
- [ ] **Host the dinner.** *(Adam)*
